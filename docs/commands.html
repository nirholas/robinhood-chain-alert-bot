Command reference

The same commands work on Telegram (as /watch …) and Discord (as slash commands). In a group or server, config commands are limited to admins; anyone can run list, premium, and help.

Watch targets

TargetWhat you getTier
launchesEvery new token on NOXA and The Odyssey. Add noxa or odyssey to filter.Free
graduationsOdyssey bonding curves that fill and migrate to a locked Uniswap v3 pool.Free

Managing your watches

CommandDoes
watch <target> [n]Start watching. Optional threshold: USD for whales/tokens, percent for premiums/rugs/stocks.
unwatch <target>Stop watching one target. unwatch all clears everything.
listYour subscriptions, thresholds, tier, digest, and quiet-hour settings.
threshold <target> <n>Change a subscription's threshold, e.g. threshold whales 25000.
digest on [min] / digest offBatch alerts into a periodic digest (default every 60 minutes) instead of delivering each one.
quiet <from> <to>Quiet hours in UTC, e.g. quiet 22 7. Alerts batch and deliver after. quiet off to disable.
premiumYour premium status and how to upgrade.
helpThe full reference, in-chat.

Examples

watch launches noxa        # only NOXA launches
watch whales 10000         # chain-wide trades ≥ $10k
watch TSLA                 # TSLA moves + on-chain premium
watch 0x…                  # one memecoin, fully
watch premiums 3           # Stock Tokens ≥ 3% off oracle (premium)
digest on 120              # one digest every 2 hours
quiet 23 8                 # mute 23:00-08:00 UTC
Every command answers, always. Unknown commands return help, empty states tell you what to try next ("you watch nothing yet, try watch launches"), and you never see raw JSON.

Free vs premium at a glance

Free: up to 3 subscriptions, alerts batched to a 60-second minimum. Premium: unlimited subscriptions, real-time delivery, and the premiums and rugs detectors. See pricing.
